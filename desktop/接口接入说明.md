# 本地语音识别接口

默认模型为 **Qwen3-ASR-1.7B Q5_K**，文件时间戳使用 **Qwen3-ForcedAligner-0.6B**。
桌面界面、任务管理、音频识别和 Windows 输入分别位于独立模块，接入识别接口不会打开麦克风、修改剪贴板或自动打字。

## 1. 启动

打开根目录的“打开语音助手.cmd”，即可同时使用悬浮窗和 HTTP 接口。

如果只需要后台识别，双击“启动接口服务.cmd”。这时不打开悬浮窗，也不监听键盘。
两种入口共享单实例，请任选一种启动。使用“停止语音助手.cmd”可关闭空闲服务。

- 地址：`http://127.0.0.1:8765`
- 令牌文件：`D:\Project\语音识别\desktop\data\api-token.txt`
- 认证头：`Authorization: Bearer <令牌文件内容>`
- 仅监听本机；默认不开启跨域。网页可由自己的后端转发请求，也可以在启动前设置环境变量 `SPEECH_DESK_ORIGINS` 为允许的完整来源，多个来源用逗号分隔。
- 原始识别 WebSocket 在 `127.0.0.1:6016`，业务系统通常使用下面的 HTTP 或 Python 封装即可。

## 2. HTTP 接口

| 方法与路径 | 用途 |
| --- | --- |
| `GET /health` | 查看模型就绪状态，无需令牌 |
| `POST /v1/transcribe` | 同步转录，返回完整任务和结果 |
| `POST /v1/jobs` | 创建异步任务，立即返回任务 ID |
| `GET /v1/jobs/{id}` | 查询任务进度、错误和结果 |
| `GET /v1/jobs` | 查询最近 30 个任务 |
| `DELETE /v1/jobs/{id}` | 取消等待中或进行中的任务 |
| `GET /v1/jobs/{id}/files/text` | 获取文字文件 |
| `GET /v1/jobs/{id}/files/json` | 获取结构化结果 |
| `GET /v1/jobs/{id}/files/srt` | 获取字幕，有时间戳时可用 |
| `POST /v1/shutdown` | 退出空闲服务；存在任务时返回 409 |

### 方式 A：提交本机文件路径

`POST /v1/jobs` 或 `POST /v1/transcribe`，请求头 `Content-Type: application/json`：

```json
{
  "file_path": "D:\\Audio\\meeting.m4a",
  "language": "auto",
  "timestamps": true
}
```

路径必须是服务所在电脑上的绝对路径。`timestamps: false` 可以省略对齐步骤，加快仅取文字的调用。
自动分段处理长录音，不会将整段解码音频一次性载入内存。

### 方式 B：上传音频内容

将 WAV、MP3、M4A、MP4 等文件的二进制内容直接作为请求体上传，`Content-Type: application/octet-stream`。
`X-Filename` 可以提供原始文件名，中文请进行 URL 编码。单次上传上限 512MB，更大的本机文件使用方式 A。
不使用 multipart/form-data；直接发送文件内容即可。

### 返回格式

创建异步任务返回 HTTP 202。查询结果示意：

```json
{
  "id": "任务ID",
  "status": "succeeded",
  "progress": 1.0,
  "output_dir": "D:\\Project\\语音识别\\识别结果\\日期\\任务目录",
  "error": "",
  "result": {
    "text": "识别出的文字。",
    "duration": 9.551,
    "elapsed": 2.5,
    "model": "Qwen3-ASR-1.7B-Q5_K",
    "tokens": ["识", "别", "出", "的", "文", "字", "。"],
    "timestamps": [0.1, 0.3, 0.5, 0.8, 1.0, 1.3, 1.5]
  }
}
```

以上为结构示意，耗时不是性能承诺。`duration`、`elapsed`、`timestamps` 的单位均为秒。
关闭对齐时，底层可能返回估计时间戳，不适合作为精确字幕。

任务状态：`queued`、`running`、`cancelling`、`cancelled`、`succeeded`、`failed`。
`progress` 为 0～1。完成前 `result` 为空；失败原因见 `error`。服务重启后可查询已有任务和结果，未完成任务会标为中断，不自动重跑。

同步接口最多等待一小时，超时仍在处理时返回 HTTP 202，可用返回的 ID 继续查询。
调用方建议：短录音同步调用；会议录音使用异步任务并每秒查询一次。

### Python 调用 HTTP（只用标准库）

```python
import json
import time
import urllib.request
from pathlib import Path

base = "http://127.0.0.1:8765"
token = Path(r"D:\Project\语音识别\desktop\data\api-token.txt").read_text().strip()

def request(method, route, payload=None):
    req = urllib.request.Request(
        base + route,
        data=None if payload is None else json.dumps(payload).encode("utf-8"),
        headers={"Authorization": "Bearer " + token, "Content-Type": "application/json"},
        method=method,
    )
    with urllib.request.urlopen(req, timeout=30) as response:
        return json.load(response)

job = request("POST", "/v1/jobs", {"file_path": r"D:\Audio\meeting.m4a"})
while job["status"] not in {"succeeded", "failed", "cancelled"}:
    time.sleep(1)
    job = request("GET", "/v1/jobs/" + job["id"])
if job["status"] == "succeeded":
    print(job["result"]["text"])
else:
    raise RuntimeError(job["error"] or job["status"])
```

其他语言可按同样的 HTTP 协议接入。`examples/http_client.py` 为可执行示例。

## 3. Python 模块调用

将项目内的 `desktop` 包安装到业务系统自己的 Python 环境：

```powershell
pip install -e "D:\Project\语音识别\desktop"
```

先启动上述桌面程序或后台服务，然后直接调用：

```python
from local_asr import ASRClient

client = ASRClient(workspace=r"D:\Project\语音识别")
result = client.transcribe(r"D:\Audio\meeting.wav", timestamps=True)
print(result.text)
print(result.to_dict())
```

这是直接调用本地识别 WebSocket 的同步模块，不经过桌面界面和 HTTP 任务队列。
也支持 `language="auto"`、`cancel=threading.Event()` 和 `progress=回调函数`。
该模块仅返回识别数据；需要队列、持久化、取消和自动导出时，使用 HTTP 任务接口。

## 4. 目录和维护

```text
SpeechDesk/SpeechDesk.exe       已打包的应用，无需用户安装 Python
desktop/src/local_asr/
  engine.py                    ASRClient：解码、分段、识别、结果结构
  processes.py                 本地识别进程管理
  jobs.py                      持久化任务与 TXT / JSON / SRT 导出
  service.py                   共用服务层
  api.py                       HTTP 接口、认证、上传
  dictation.py                 桌面麦克风与快捷键
  win_input.py                 Windows 窗口选择和文字输入
  ui.py                        悬浮窗
  main.py                      GUI / headless 入口
desktop/data/                  令牌、任务库、临时文件、日志
识别结果/                      按日期和任务保存的结果
CapsWriter-Offline/            原有引擎、模型和 FFmpeg
```

模型和 FFmpeg 保留在原有目录，请一起保留。可整体移动项目；其他系统配置的绝对路径需要相应更新。
重建应用：`powershell -ExecutionPolicy Bypass -File desktop/build.ps1`。构建依赖版本见 `requirements-build.txt`。
运行环境安装：`powershell -ExecutionPolicy Bypass -File tools/Install-Runtime.ps1`；引擎配置模板保存在 `configs/config_server.py`。
